KKL 409.1 cable for VAG: how to choose one that works

To diagnose a Volkswagen, Audi, SEAT or Skoda from before ~2004 you need a KKL cable (also sold as “VAG-COM 409.1”). It is a cheap USB adapter, about €10-20, but not all of them work: what matters is the chip inside.

What it is for and why an ELM327 will not do

Older VAG cars speak KW1281, the group's own protocol, over the K-line (pin 7 of the diagnostic connector). It is very different from OBD2: the computer has to wake the control unit by sending its address at 5 baud and then acknowledge every byte it receives by sending back its complement, with timings of a few milliseconds.

An ELM327 cannot do that byte-by-byte acknowledgement, so it does not work for KW1281. A KKL cable, on the other hand, just turns the K-line into a serial port and lets the program handle the whole protocol. That is why it reaches every control unit: engine, transmission, ABS, airbag, cluster, convenience, radio…

Do I need one?

  • If your VAG car is older than 2004, especially a diesel: in Europe EOBD became mandatory for petrol cars in 2001 and for diesels in 2003-2004. A 2000 1.9 TDI has the 16-pin connector but usually does not answer an OBD2 reader.
  • If an ELM327 tells you that “the vehicle does not respond to OBD2” with the ignition on.
  • If you want to reach control units OBD2 cannot see (ABS, airbag, cluster, convenience) or run output tests, basic settings, adaptation or coding.

The chip is what matters: FTDI yes, CH340 no

The 5-baud wake-up needs precise control of the serial port's break signal. FTDI FT232RL or FT232RQ chips do it well; CH340/CH341 and PL2303 chips do not: the cable shows up in the system, but the control unit never answers.

How to tell which chip yours has:

  • Windows: Device Manager → Ports (COM & LPT) → the cable's port → Properties → Details → Hardware Ids. VID_0403&PID_6001 is FTDI; VID_1A86 is CH340; VID_067B is PL2303.
  • Linux: run lsusb with the cable plugged in. 0403:6001 Future Technology Devices is FTDI; 1a86:7523 is CH340.

When buying, look for “KKL 409.1 FTDI” or “FT232RL” in the listing, and be wary of the ones that do not name the chip.

Fake FTDI chips

Many cheap cables carry counterfeit FTDI chips. Some official drivers detect them and make them useless: the port appears but does not communicate. Installing an older FTDI driver usually fixes it. If you can, buy from a shop that accepts returns.

Cables with a 4-position switch

“KKL 409.1 + Fiat ECU Scan” cables have a 4-position switch that changes which connector pins the K-line goes to. They work for VAG in position 1 (K-line to pin 7). If it does not answer, try the others.

What does not work

  • ELM327 adapters with an HS-CAN/MS-CAN switch: they are for Ford (FORScan); their USB chip goes to the ELM327, not to the K-line.
  • The “VAG K+CAN Commander”: it is meant for immobilizers and keys, and its K-line side is not guaranteed. We do not recommend it.
  • There is no off-the-shelf wireless KKL cable: Bluetooth and WiFi add too much delay for KW1281 timings.

Setting it up

  • Windows: Windows Update installs the driver. Set the latency to 1 ms in Device Manager → Ports → USB Serial Port → Properties → Port Settings → Advanced → Latency Timer. It stops the session from dropping. It has to be done on each computer.
  • Linux: no driver needed, and OBD2Desk sets the latency itself. Your user must be in the port's group: sudo usermod -aG dialout $USER (on Arch, uucp) and log in again. On Ubuntu and Mint, if the cable does not show up as /dev/ttyUSB0, remove the braille driver: sudo apt remove brltty.

If it does not connect

  • Ignition on (the engine can be off to read fault codes) and the right port selected in the program.
  • “No 0x55 sync byte”: the control unit did not answer. Check the chip, the switch and the driver. An aftermarket radio can block the K-line: disconnect it to test.
  • “KWP2000 keywords”: that control unit speaks the newer KWP2000 rather than KW1281. Use an ELM327 in OBD2 mode.
  • Try the program first with the “Simulator (no car)” port to rule out a problem on the computer.
