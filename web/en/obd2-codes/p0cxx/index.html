Before replacing parts

  • Write the faults down before clearing them, with the fault type and, on OBD2, the freeze frame data (engine speed, temperature and load when the fault happened).
  • Clear them and see whether they come back. A fault that does not return after several starts may be old; one that comes back straight away is current.
  • Check the wiring and connectors first when the fault is a short, an open circuit or intermittent.
  • Look at the component's measured values with the engine running: a sender giving an absurd value (−40 °C coolant, for example) confirms the fault.
