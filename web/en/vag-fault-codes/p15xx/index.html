VAG fault codes P15xx: Idle, throttle, boost pressure, camshaft and relays

The 87 VAG-specific P15xx codes (Volkswagen, Audi, SEAT and Skoda) that OBD2Desk knows: Idle, throttle, boost pressure, camshaft and relays. VAG tools show them with 5 digits, from 17908 to 18007: VAG code = 16408 + P1 number.

A generic OBD2 reader only shows them as a “manufacturer code”; OBD2Desk also describes them over OBD2 when the VIN is from a VAG car.

Type the 5-digit code, the P code or a word from the description.

Descriptions are for guidance and come from public VAG documentation. The exact meaning can vary with the control unit and year: check it against your car's workshop manual.

Before replacing parts

  • Write the faults down before clearing them, with the fault type and, on OBD2, the freeze frame data (engine speed, temperature and load when the fault happened).
  • Clear them and see whether they come back. A fault that does not return after several starts may be old; one that comes back straight away is current.
  • Check the wiring and connectors first when the fault is a short, an open circuit or intermittent.
  • Look at the component's measured values with the engine running: a sender giving an absurd value (−40 °C coolant, for example) confirms the fault.
