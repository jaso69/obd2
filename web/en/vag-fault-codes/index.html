VAG fault codes: list and meaning

Volkswagen Group cars (Volkswagen, Audi, SEAT and Skoda) store fault codes as a 5-digit number. Here is the meaning of 738 codes, taken from the same tables OBD2Desk uses to describe them.

How VAG codes work

  • 00xxx-01xxx · classic. Used by VAG cars from before OBD2 (KW1281 protocol). The same number means the same in every control unit: 00532 is the supply voltage in the engine as well as in the ABS.
  • 16xxx · generic OBD2. These are P0xxx codes written the VAG way: VAG code = 16384 + P0 number. For example, 16684 = P0300 (misfire detected).
  • 17xxx-18xxx · VAG-specific. These are the P1xxx codes: VAG code = 16408 + P1 number. For example, 17978 = P1570 (engine control unit locked by the immobilizer).

An OBD2 reader with an ELM327 shows them as P0xxx and P1xxx; a program that speaks KW1281 with a KKL cable shows the 5 digits. OBD2Desk shows both.

Fault type: the number that follows

Besides the code, the control unit gives a fault type that says what is wrong with the component. OBD2Desk shows it in brackets: 00522 Coolant temperature sender (G62) [05 - Open circuit].

If it also says intermittent, the fault came and went: usually a loose contact or a chafed wire. A short or an open circuit points first to the wiring and connector rather than the part itself.

Before replacing parts

  • Write the faults down before clearing them, with the fault type and, on OBD2, the freeze frame data (engine speed, temperature and load when the fault happened).
  • Clear them and see whether they come back. A fault that does not return after several starts may be old; one that comes back straight away is current.
  • Check the wiring and connectors first when the fault is a short, an open circuit or intermittent.
  • Look at the component's measured values with the engine running: a sender giving an absurd value (−40 °C coolant, for example) confirms the fault.

Descriptions are for guidance and come from public VAG documentation. The exact meaning can vary with the control unit and year: check it against your car's workshop manual.
