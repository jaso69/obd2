VAG fault codes Classic 00xxx-01xxx: engine, transmission, ABS, airbag, cluster, convenience and radio

The 93 most common 5-digit VAG fault codes of cars from before OBD2 (KW1281 protocol): Volkswagen, Audi, SEAT and Skoda up to ~2004. The same number means the same in any control unit.

They are read with a KKL cable; an OBD2 reader with an ELM327 does not see them. After the code, the control unit gives the fault type (short circuit, open circuit, signal too high…).

Type the 5-digit code, the P code or a word from the description.

Descriptions are for guidance and come from public VAG documentation. The exact meaning can vary with the control unit and year: check it against your car's workshop manual.

Before replacing parts

  • Write the faults down before clearing them, with the fault type and, on OBD2, the freeze frame data (engine speed, temperature and load when the fault happened).
  • Clear them and see whether they come back. A fault that does not return after several starts may be old; one that comes back straight away is current.
  • Check the wiring and connectors first when the fault is a short, an open circuit or intermittent.
  • Look at the component's measured values with the engine running: a sender giving an absurd value (−40 °C coolant, for example) confirms the fault.

Other VAG code lists

  • 16xxx = P0xxx · generic OBD2 codes in VAG format
  • P11xx · O2 sensors, fuel trim and load
  • P12xx · Injectors, injection timing, turbo and cooling
  • P13xx · Ignition, knock and misfires
  • P14xx · EGR, EVAP and exhaust temperature
  • P15xx · Idle, throttle, boost pressure, camshaft and relays
  • P16xx · Power supply, pedal, MIL, control unit and data bus
  • P17xx · Automatic transmission
  • P18xx · Automatic transmission and data bus
